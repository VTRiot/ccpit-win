# 人間へ渡すコマンドの安全要件

CC が人間に実行を依頼するコマンドは、**貼って実行するだけで安全に完結する形**にする。

## 禁止
- 外部から取得したスクリプトの実行、`Invoke-Expression` / `eval` 相当
- 不要な管理者権限の要求
- ワイルドカード・再帰削除
- 秘匿値を標準出力へ出すこと（件数・真偽で確認させる）

## 要件
- **冪等**にする（2 回流しても壊れない）
- 対象パスは操作前に解決し、実体を確認してから操作する
- シェルは人間の操作環境に合わせる（Windows なら PowerShell）
- 期待値を明示する（「該当 0 件になる」等）。人間に結果の解釈を委ねない
- 報告書を伴う依頼では、HTML 報告書のコードブロックに置く（チャット本文だけに置かない）

deny 対象ファイルの編集依頼に固有の手順は `rules/denied-file-handoff-as-commands.md`。
