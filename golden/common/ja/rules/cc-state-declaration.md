# CC State 明確化と自己再起動

設定変更（settings/hooks/skills/plugins）は起動時にスナップショットされ、実行中セッションには反映されない。
CCPIT が対象ノードの全 CC を一括再起動して反映を保証する。各 CC は以下に従う。

- ターン終了時、自分の State（稼働中 / 待機中 / アイドル、待機中なら待機理由）を CC ランタイムの
  session 状態と矛盾しない形で扱う。State は CCPIT の再起動安全判定の根拠になる。
- CCPIT の**再起動要求フラグ**（`restart-request-gate` が検知）を受けたら、いまは安全な完了点である。
  クリーン引き継ぎメモ（目的・完了済み・次操作のみ。誤形式出力は引用しない）を残し、`/exit` で一度
  終了してから `claude --resume <セッションID>` で再起動し、変更後の設定を反映せよ。
- 稼働中・待機中のタスク途中で外部から強制終了されるとタスク状態は復元されない。だからこそ
  「安全な完了点で CC 自身が再起動する」代行経路を優先する。
