# md2html.cjs を編集する時（改変ガード）

> この章を開く作業: `md2html.cjs` を編集する時

## 改変ガード

`md2html.cjs` を編集した場合は必ず `--selftest` を実行し、意図した変更なら内蔵 GOLDEN sha を再計算して更新する（selftest FAIL の放置は破損とみなす）。押せる図（`figure_links`）は、固定の sha に加えて、関係を両側から確かめる検査（`selftestFigLink`: 宣言なし扱いの出力がキー無しと同一・有効な宣言の差分は id／データ島／専用の CSS・JS・チップだけ・データ島の全 `to` が出力中に 1 度だけ現れる）も `--selftest` に含む。コード引用の照合（`selftestCite`: 偽の入出力でディスクにも git にも触れず、一致・中身違い・範囲ずれ・ファイル無し・範囲超過・行末の空白・rev・UNVERIFIABLE・実物のスナップショット・秘密を含みうるファイルを読まずに止めることと診断に秘密を出さないことを固定）と必須見出しの検査（`selftestHeadings`: コードブロック・引用・行の途中の見本の見出しでは満たされず、本物の見出しなら満たされる）も同様に含む。

成果物の欄・表・DA バーの検査（`selftestOutputsTables`）は、宣言あり／なし／無効だけの宣言の出力、宣言あり→なし→ありを同じプロセスで順不同に描画しても状態が漏れないこと、描画が `fs` に触れないこと、`file:///` の固定の URL（Windows 上では `url.pathToFileURL` との一致も）、表のセル分割（バックスラッシュの偶奇）と列数の `--lint` の両側、印付き数と `da_scale: table` の幅を固定する。SKILL.md の章立ての検査（`selftestChapters`）は、本体の道案内と `chapters/` の過不足・本体の上限（`SKILL_BODY_MAX_LINES`・`SKILL_BODY_MAX_BYTES`）を、正しい見本と壊した見本で固定し、このフォルダの実物も検査する。章の無い版（英語版など）は該当なしで通る。配布物の検査では厳格モード（`checkChapterSet(dir, { strict: true })`）で、`SKILL_CHAPTERS` の全章と `SKILL.md` が揃っていることを必須にする。章を足す・減らすときは `SKILL_CHAPTERS`・本体の道案内・`chapters/` の 3 か所をそろえ、章のファイル名は変えない（配布は上書きだけでファイルを消さないため、名前を変える・章を減らすと、古い章が配った先の各 PC に残る）。**古い章が残ることは前提として扱う**: 配った後の実物のフォルダを見る通常の `--selftest`（厳格でない検査）は、本体から参照されない章を失敗にせず、`[SELFTEST NOTE]` で名前を知らせるだけにする。本体が参照する章が無い（欠け）・本体が上限を超える、は今までどおり失敗にする。本体に章への道案内が 1 つも無い版（章の無い英語版など）に古い章が残っているときも、失敗にはせず別の文言で知らせる（道案内を失った日本語版の本体は、厳格モードと台帳の照合で止める）。配布物の検査（厳格モード）は、期待する章（`SKILL_CHAPTERS`）と過不足なく一致することを求め、期待に無い章で落ちる。厳格モードは、提案が運ぶファイル一式（章を減らす・名前を変えた後の一式）に対して使い、各 PC に残った古い章には使わない。古い章を各 PC から消したいときは、提案では消せないので、利用者が手で消すと知らせる。
