# 押せる図（`figure_links:`）

> この章を開く作業: 図のノードを押して、詳細の書いてある場所へ飛べるようにする時

## 押せる図（任意・`figure_links:` ブロック）

報告書の図（mermaid の `flowchart` / `graph`）の**ノードを押すと、その詳細が書いてある場所（見出し・表の行・箇条）へ飛び**、右下の「↩ 図に戻る」で**図の位置へ戻れる**。「図のこの項目は何の話だっけ」を、図から 1 手で思い出せるようにするための機能（**新 MD 構文ゼロ**。`hover:`・`comments_resolved:` と同じブロック宣言）。**宣言した文書だけで効く**。

### 書き方（frontmatter）

```yaml
figure_links:
  - M7 || row: M7
  - D || heading: 済んだ段
  - C || item: M23
```

- 1 行 = 1 つの対応。形は `- ノードID || 種別: 文字列`（`||` の前がノード ID、後ろが「種別: 文字列」）。**値が空のブロック**として書く（`figure_links:` の次の行から、字下げした `- ` の行）
- **ノード ID**: 図の原文のノード ID（`M7["M7 英語版"]` の `M7`）。使える文字は英数字と `_` だけ（それ以外は `--lint` が error）。ノード ID が図の**原文に 1 度も現れない**宣言は `--lint` が error
- **種別**は次の 3 つ。**表の行**と**箇条**は、行・箇条の位置でなく「テキスト」で指す:
  - `heading: 見出しのテキスト` — 見出し（**H2〜H6**。H1 は文書タイトルでも本文中の 2 つ目以降でも指せない）のテキストが完全一致。「本報告書の読者と目的」「結論の概要」「スコープ外提案（Pending）」の各見出しも指せる
  - `row: セル 1 のテキスト` — **表の 1 列目のセル**のテキストが完全一致する本文の行（ヘッダ行は対象外）。例: 1 列目が `M7` の行なら `row: M7`
  - `item: 箇条の先頭のテキスト` — 箇条の本文が完全一致、または「そのテキスト＋空白」で始まる箇条。例: `- M23 全試験で…` なら `item: M23`（`M2` は `M22` を拾わない）
- **照合の正規化**（宣言側・文書側に同じ処理）: リンク `[t](u)` は `t`（リンクの解釈はレンダラ本体と同じで、最初の `)` でリンク先を閉じる。`u` に `)` を含む書き方は、その後ろの `)` が文字として残る）、`**` とバッククォートを除き、NFC に正規化し、空白（全角空白を含む）の連なりを半角空白 1 個にして前後を切る。太字・コード・リンクを含む見出し・セル・箇条も、見た目のテキストで指せる
- **飛び先は 1 つに決まること**。0 件でも 2 件以上（同じテキストの見出しが複数・同じ 1 列目の行が複数の表にある、など）でも `--lint` は error（黙って先頭を選ばない）。複数のノードが**同じ飛び先**を指すのは可（多対一）。同じノード ID を複数の宣言に書くのは不可
- 表・箇条は、admonition（`> [!NOTE]` など）・引用・「読者と目的」「結論の概要」「スコープ外提案（Pending）」の各パネルの中にあっても、描画された位置で数える（ネストした箇条も、入れ子の各項目が 1 つの箇条）。`item` は番号付き・番号なしどちらの箇条も指せる

### 押したときの動き

- ノードを押す（Enter / Space でも同じ）と、飛び先へ移って**枠線＋背景で強調**し（`prefers-reduced-motion` ではアニメ無し）、飛び先へフォーカスを移して、画面外の `aria-live` 領域へ「『…』へ移動しました」と通知する。飛び先が非アクティブなタブの中なら、そのタブを開いてから移る
- 右下に **「↩ 図に戻る」チップ**（既存の「↩ 戻る」の上）が出る。押すと、ノードを押す直前の位置へ戻り、押したノードへフォーカスを返す。戻り先は小さなスタック（上限 20）なので、飛び先から別の図を押しても 1 つずつ戻れる。図が別のタブにあれば、そのタブを開いてから戻る
- 強調・一時的な `tabindex` はスタックから再計算する。同じ飛び先へ 2 回飛んで 1 回戻っても、残る方の強調は消えない

### 宣言の無い文書・無効な宣言・安全

- **予約キー**: `figure_links` は予約キー（従来は未知キーとして無視されていた）。**値が空でない**書き方（`figure_links: foo`・`figure_links: [a, b]`）は宣言とみなさず、描画も `--lint` も従来どおり（警告も出ない）。値が空のブロックで読める行が 1 件も無いときも宣言とみなさない（描画は従来どおり）。ただし、値が空で字下げした子行があるのに読めない行がある場合は、ブロック形の誤用として `--lint` が警告する
- 宣言が無い文書の HTML は、この機能を足す前後で**同じ入力ならバイト単位で同じ**（既存の文書の大きなコーパスで確かめてあり、`--selftest` も固定している）。**有効な宣言が 0 件の文書**も、CSS・JS・データ島・チップ・`id` 属性のいずれも注入せず、`figure_links` 行を除いた同じ文書の出力と同じになる（原文のハッシュ由来の属性 `data-src-sha256` とフッタの sha だけは、原文が違うので別の値になる。`--selftest` はこの 2 つを正規化して比べる）。有効な宣言が 1 件以上あるときだけ、有効な飛び先の `<tr>`・`<li>` に `id="fl-N"`（通し番号）が付き、データ島・専用の CSS・固定ローダ・チップが入る
- **mermaid の安全の水準（`securityLevel`）は緩めない**。`click` 構文は使わない。ローダは mermaid が描画した後の SVG の `g.node`（`id` は `flowchart-<ノードID>-<連番>`）を、宣言と**文字列の等価比較**で突き合わせ、クリックを結線する（宣言値から正規表現・セレクタを組み立てない）。`innerHTML` は使わず、外部の読み込みは足さない
- **結線の印は JS 側のプロパティに持つ**（属性にしない）。mermaid は描画中に `pre` の内部へ一時の SVG を作り、文字列へ直してから差し替えるため、属性は複製されるがイベントの登録は失われる。ローダはこの差し替えを `MutationObserver` で検知して結線し直す
- 静的検査（`--lint`）は**必要条件だけ**を見る（ノード ID が図の原文に現れるか。コメント・引用符の除去はしない）。**実際にノードが押せるかは実行時に確かめる**: 描画済みの図が 1 つ以上あるのに結線できなかった宣言は、`console.warn`・`<html data-fl-unwired="ノード ID…">`・画面左下の「押せない宣言」の注意で示す（図が 1 つも描画されていない間＝オフライン・読み込み失敗・描画待ちは判定しない）。例: 図の原文のコメントにだけ書かれたノード ID は `--lint` を通るが、実行時に「押せない宣言」になる。**宣言を書いたら、ブラウザで一度開いて、注意が出ていないことを確かめる**
- `--verify`（HTML⊆MD・MD⊆HTML）は不変: 文言は CSS 擬似要素・属性・ローダの実行時の文字列で、静的なテキストノードは増えない。宣言がある文書は、報告書型でなくても `--lint` が `figure_links` を検査する（error があれば exit 1。`--verify` も lint の error を失敗として扱う）

### 制約

- 対象は mermaid の `flowchart` / `graph` のノード（`subgraph` の枠・辺・他の図種は押せない）
- ノード ID を複数の図が共有する場合は、ID が現れる図すべてで結線する（宣言は文書で 1 組）
- 飛び先は、見出し・表の本文行・箇条。表のヘッダ行・段落・コードブロックは指せない
