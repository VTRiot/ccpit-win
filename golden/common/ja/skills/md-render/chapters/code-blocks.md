# コードブロックのコピーボタン

> この章を開く作業: コマンドやコードをコピーさせるブロックを書く時。`nocopy`・`title` を付ける時

## コードブロックのコピーボタン（全文書・既定 on）

通常のコードブロック（フェンス）には、上に**ラベルと「コピー」ボタンのバー**が付く。ボタンを 1 回押すとコードの中身だけがクリップボードに入り、ターミナルへそのまま貼れる（読み手にコマンドを手で写させない — 写し間違いが事故の元になるため。2026-09-24 運用者指示）。

- **付くブロック**: 通常のフェンス（admonition・引用の中も含む）。**mermaid / svg の図には付かない**。貼る物でないブロック（出力例・ログ・文字で描いた図など）は info 文字列に `nocopy`（`no-copy` も可）を足すと付かない。例: ` ```text nocopy `
- **ラベル**: info 文字列の `title="..."` があればそれ（例: ` ```bash title="再起動する" `）、無ければ言語名、どちらも無ければ `code`。人に実行してもらう手順では、何をするコマンドかを `title` に書く
- **コピーされる中身**: `<pre>` 内 `<code>` の textContent。HTML エスケープ（`&amp;` 等）は元の文字に戻り、ボタンやラベルの文字は混ざらない。**末尾の改行は全て落とす**（貼った瞬間に最終行が実行されないように）。行の途中の改行・行継続の `\`・タブはそのまま。閉じた `<details>` や非表示タブの中でも空にならない（表示状態に左右される innerText は使わない）
- **書き込み経路**: 押した処理の中で、まず画面外の `textarea` ＋ `execCommand('copy')` を同期的に試し、失敗した時だけ同じ処理の中で `navigator.clipboard.writeText`（secure context のみ）を呼ぶ。どちらもユーザー操作の有効期間内に呼ばれるので、clipboard API が権限で拒否される環境（権限を与えられていない iframe 等）でも、拒否を待ってから切り替える順序のような有効期間切れが起きない。押した後は約 1.6 秒「コピーした」（緑）、両経路とも失敗したら「コピー失敗：手で選択して」（赤）を出し、クリップボードは変えない。Windows ではブラウザが改行を CRLF にしてクリップボードへ入れる
- **読み上げ**: 結果は見た目に加え、実行時に JS が作る `aria-live` 領域（`role="status"`・画面外）へ「コピーしました」「コピーできませんでした。コードを選択して手でコピーしてください」と文で知らせる。静的 HTML には何も足さない
- **見た目**: テーマ（Day / Dark）に関係なく端末らしい暗い帯に固定する（Day では「貼る物」がひと目で分かる）。色は外枠 `.cb` 上の `--cb-*` 変数で持ち `:root` を触らない。キーボードで Tab 移動するとボタンに枠線が出る。長い行はブロック内だけ横スクロールし、ページ全体は横に動かない。印刷時はボタンを出さない
- **決定論・検証との関係**: ラベルは `data-label` → CSS `attr()`、ボタン文字は CSS 擬似要素、支援技術向けの名前は `aria-label`、結果の読み上げ文は実行時に JS が入れる ＝ **静的テキストノードを増やさない**（`--verify` の HTML⊆MD / MD⊆HTML は不変）。CSS とローダは**コピー対象のブロックを 1 つ以上出力した文書にだけ**注入する。コピー対象の無い文書（mermaid / svg / `nocopy` のブロックだけの文書を含む）は出力が変わらない。`<pre>` の `data-lang` 属性は従来どおり info 文字列全体（小文字化）のまま
- **JS が動かない環境**: ボタンは JS の準備完了（`html.cb-ready`）まで隠す。押しても何も起きないボタンは見せず、ラベルとコードは読める
- **外部依存なし**: CSS と JS は HTML に埋め込む（外部ファイルを読めない表示環境 — 例: claude.ai の Artifact — でも機能が消えない）。クリックは document への委譲 1 本で扱うため、後から DOM に足した `.cb` にも効く
