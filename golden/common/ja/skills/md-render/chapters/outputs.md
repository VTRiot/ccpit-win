# 成果物の欄（置き場所へクリックで行く）

> この章を開く作業: 報告書が作った成果物（CSV・設定・データなど、オーナーが使うファイル）の置き場所を、報告書に載せる時

## 何のための機能か

成果物の名前だけが本文に書いてあっても、オーナーは置き場所を探すことになる。frontmatter に `outputs:` を宣言すると、HTML の**最初の画面**（ヘッダの直下、「本報告書の読者と目的」の上）に成果物の欄が出て、クリックで置き場所のフォルダへ行け、パスをコピーできる。**成果物を作った報告書では、宣言を書く**。

## 書き方（frontmatter の `outputs:` ブロック）

```yaml
outputs:
  - 提案値 CSV || file: C:\Work\成果 データ\261003-01_Proposed.csv
  - 出力フォルダ || dir: C:\Work\out
```

- 1 行 = 1 つの成果物。形は `- 名前 || 種別: パス`。値が空のブロックとして書く（`outputs: [a, b]` や 1 行形は宣言とみなされず、`--lint` が error にする）
- **名前**: 欄に表示する人向けの名前（空にしない）。`||` を含めない
- **種別**: `file`（ファイル）か `dir`（フォルダ）。**ファイルかフォルダかは、実体を調べず種別で決める**（HTML をファイルの有無に左右させないため）
- **パス**: **ドライブ文字から始まる Windows の絶対パス**（`C:\...` か `C:/...`。区切りは混在してよい）。表示とコピーは**書いたとおり**に出る。相対パス・`~`・UNC（`\\server\...`）・`\\?\` は error（相対パスは MD の置き場所で結果が変わるため解決しない）
- パスの error になる形: `.` と `..` の部分・区切りの連続・`< > : " | ? *` を含む部分（ドライブ文字のあとのコロンを除く）・部分の末尾のドットと空白・予約名（`CON` `PRN` `AUX` `NUL` `COM1`〜`COM9` `LPT1`〜`LPT9`。拡張子付きを含む）・制御文字・`file` のパスが区切りで終わるもの
- 同じ場所（大文字小文字・区切りの違いを区別しない）を 2 回宣言すると error。`file` の親フォルダと同じ場所の `dir` を宣言すると、同じ組にまとまる

## HTML に出るもの

- 成果物の欄: フォルダごとの組。各組に **「フォルダを開く」ボタン**（`file:///` のリンク）と**フォルダのパスのコピー用ブロック**、その下に各ファイルの名前と**ファイルのパスのコピー用ブロック**。コピーは通常のコードブロックのコピーボタン（`chapters/code-blocks.md`）と同じ部品で、貼れる形のパスがクリップボードに入る
- 欄の見出しとボタンの文字は CSS の擬似要素で出る（静的なテキストを増やさない）。`--verify` は宣言した文書でも両方向とも通る
- 宣言の無い文書の HTML は、この機能を足す前後で 1 バイトも変わらない。HTML は MD の中身だけで決まり、ファイルの有無・MD の置き場所・実行した OS に左右されない

## `--lint` が知らせること

- **error**: 壊れた行（`||` が無い・名前が空・種別が `file` か `dir` でない・パスが空）、値が空でない形、上の「パスの error になる形」、同じ場所の重複
- **warning**: パスが実在しない、`file` と宣言したのに実体がファイルでない（`dir` も同様）。**別の PC で読むと必ず出る**（描画は有無を見ない）。成果物を作った PC で `--lint` して、出ないことを確かめる

## 限界（書き手が知っておくこと）

- **フォルダを開くボタンは、ブラウザの `file:///` のフォルダ一覧が開く**。エクスプローラーは開かない。エクスプローラーで開きたいときは、フォルダのパスをコピーして、エクスプローラーのアドレス欄へ貼る
- **ファイルを開くリンクは出さない**。Chromium で実測した結果、`file:///` のファイルのリンクは、`.csv` と `.xlsx` を押すと表示せずにダウンロードし、ダウンロードのフォルダに複製を作る（`.txt`・`.json`・`.md` は表示される）。オーナーが複製を使うと原本と取り違えるので、ファイルへのリンクは作らない。ファイルは、置き場所のフォルダを開いてから選ぶか、ファイルのパスをコピーして使う
- **http で配った HTML からは `file:///` のリンクは開かない**（実測: 押しても遷移せず、ブラウザは「Not allowed to load local resource」と拒む）。そのときもパスのコピーは効く。HTML は `file:///` で直接開く
- **別の PC では開かない**: 報告書がクラウドなどで別の PC に写されると、`C:\` のパスはその PC に無く、リンクは開かない（仕様。リンク先を書き換える仕組みは無い）
